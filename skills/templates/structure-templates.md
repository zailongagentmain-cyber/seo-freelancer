## 结构公式

### 1. 总分总结构
- **公式**: 概述 → 详细展开 → 总结行动
- **适用**: 教程、指南类
- **状态**: 活跃
- **效果反馈**: 待记录

### 2. 清单式结构
- **公式**: 数字 + 要点列表 + 每个要点的解释/示例
- **适用**: 技巧、方法类
- **示例**: "5个有效的SEO技巧：1. ... 2. ..."
- **状态**: 活跃
- **效果反馈**: 待记录

### 3. 对比式结构
- **公式**: A方法 → B方法 → 对比分析 → 推荐
- **适用**: 评测、对比类
- **状态**: 活跃
- **效果反馈**: 待记录

### 4. 问答式结构
- **公式**: 问题1 → 回答1 → 问题2 → 回答2 → ...
- **适用**: FAQ、知识类
- **状态**: 活跃
- **效果反馈**: 待记录

### 5. 故事线结构
- **公式**: 背景 → 挑战 → 解决方案 → 结果 → 启示
- **适用**: 案例分析、经验分享
- **状态**: 活跃
- **效果反馈**: 待记录

### 6. AI 引用优化结构
- **公式**: 主题介绍 → 核心概念 → 实践步骤 → 案例分析 → 总结行动
- **适用**: AI 搜索优化、AI 引用构建
- **状态**: 新增 (2026-03-13)
- **来源**: 本轮学习 - AI Citations 技巧

### 7. 实体集群结构
- **公式**: 核心实体定义 → 子主题1 → 子主题2 → 子主题3 → 内部链接闭环
- **适用**: 主题集群 SEO
- **示例**: "SEO → 关键词研究 → 技术SEO → 外链建设 → SEO工具"
- **状态**: 新增 (2026-03-13)
- **来源**: 本轮学习 - Entity Clusters 策略

1. 至少 **3 个 H2 标题**
2. 每个 H2 下 **2-3 个要点**
3. 每要点至少配 **1 个示例或数据**
4. 结论部分必须有 **Action Item**
