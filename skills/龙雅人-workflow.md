## 📐 内容生产流程（从选题到发布）

### 阶段 1：选题与规划
```
1. 确定目标受众和细分市场
2. 用 seo-competitor-analysis 分析竞品
3. 用关键词研究工具挖掘目标关键词
4. 确定搜索意图 (Informational/Commercial/Transactional)
5. 制定内容大纲 (包含 H2/H3 结构)
```

### 阶段 2：内容创作
```
1. 按大纲撰写初稿
2. 使用 seo-content-writer 优化
3. 融入 E-E-A-T 元素（经验、专业、权威、可信）
4. 添加案例/数据/引用来源
5. 自查内容完整度
```

### 阶段 3：SEO 优化
```
1. 关键词密度检查 (1-2% 为宜)
2. 标题标签优化 (50-60 字符)
3. Meta 描述优化 (150-160 字符)
4. H1/H2/H3 层次结构检查
5. 图片 Alt 文本检查
6. 内部链接/外部链接
7. Schema Markup 添加
```

### 阶段 4：发布前检查
```
1. 通读全文检查流畅度
2. 移动端预览
3. 加载速度检查
4. 最终 SEO 检查清单 (见下文)
5. 提交发布
```

## ✅ SEO 检查清单（每篇文章必查）

### 标题标签
- [ ] 包含目标关键词
- [ ] 长度 50-60 字符
- [ ] 唯一不重复

### Meta 描述
- [ ] 包含目标关键词
- [ ] 长度 150-160 字符
- [ ] 有行动号召 (CTA)
- [ ] 唯一不重复

### 内容结构
- [ ] 只有 1 个 H1
- [ ] 有 2-4 个 H2
- [ ] H2 下有 H3 子标题
- [ ] 段落长度适中 (3-4 句)

### 关键词
- [ ] 目标关键词在首段出现
- [ ] 关键词密度 1-2%
- [ ] LSI 关键词分布全文
- [ ] 无关键词堆砌

### 多媒体
- [ ] 有至少 1 张图片
- [ ] 所有图片有 Alt 文本
- [ ] 图片有优化文件名
- [ ] 使用 WebP 格式

### 链接
- [ ] 有 2-4 个内部链接
- [ ] 有 1-3 个权威外部链接
- [ ] 锚文本包含关键词
- [ ] 无死链接

### 结构化数据
- [ ] Article 或 FAQ Schema
- [ ] 通过 Rich Results Test

### 技术
- [ ] Canonical 标签正确
- [ ] URL 包含目标关键词
- [ ] URL 简洁 (无多余参数)
- [ ] 移动端友好

## 🎨 风格模板库

### 类型 1：教程/指南 (How-to)
```
标题: How to [动作] [目标] in [时间/步骤]
结构:
- 引言: 痛点 + 解决方案预告
- 背景: 为什么重要
- 步骤 1-5: 详细操作
- 常见错误/注意事项
- 总结 + CTA
```

### 类型 2：最佳推荐 (Best X)
```
标题: Best [产品类别] of [年份] - [具体特色]
结构:
- 引言: 快速推荐清单
- #1 详细评测 (500+ 字)
- #2-5 简要推荐
- 对比表
- 选购指南/注意事项
- FAQ
```

### 类型 3：对比分析 (X vs Y)
```
标题: [X] vs [Y] - [哪个更好/区别]
结构:
- 快速结论
- X 介绍 + 优点
- Y 介绍 + 优点
- 详细对比表
- 使用场景分析
- 最终推荐
```

### 类型 4：词汇解释 (What is X)
```
标题: What is [术语]? [完整定义]
结构:
- 一句话定义
- 详细解释
- 历史/背景
- 相关概念
- 应用场景
- 常见问题
```

### 类型 5：案例研究
```
标题: How [公司] [成果] - Case Study
结构:
- 背景介绍
- 挑战/问题
- 解决方案
- 执行步骤
- 结果/数据
- 关键教训
```

## ⚠️ 重要提醒

1. **质量 > 数量** - 100 篇优质文章 > 1000 篇垃圾内容
2. **E-E-A-T 是核心** - 展示经验、专业、权威、可信
3. **用户意图优先** - 不要为了 SEO 牺牲用户体验
4. **持续优化** - 发布后跟踪数据，不断迭代
