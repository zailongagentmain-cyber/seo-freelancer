## 技能组合思考

### 最佳组合方案

**龙雅人SEO Suite = seo (核心) + seo-content-writer (内容) + seo-competitor-analysis (分析) + seo-optimizer (技术)**

工作流程:
1. **seo-competitor-analysis** → 分析竞争对手，找出机会
2. **seo-content-writer** → 创作高质量内容
3. **seo-optimizer** → 实施技术优化
4. **seo** → 全局把控和质量审计

### 可选增强
- **seo-article-gen** → 批量生成时使用(注意联盟链接风险)
- 后续批次技能可能包含更多垂直领域技能
