## Finding 2: Google March 2026 Spam Update — Shortest in History (19.5 Hours)

## Finding 4: Google-Agent User Agent Announced for Agentic Web Browsing
**Details:** Google added a new "Google-Agent" user agent string specifically for agents hosted on Google infrastructure that navigate the web and perform actions upon user request (e.g., Project Mariner). The user agent is rolling out over weeks and uses IP ranges from user-triggered-agents.json. Google is also experimenting with the web-bot-auth protocol using the https://agent.bot.goog identity. This is the first time Google has explicitly identified AI agent traffic in server logs with a dedicated user-agent string.
**Source:** Search Engine Roundtable / Google Developers Documentation
**Date:** March 26, 2026
**Actionability Score:** 10
