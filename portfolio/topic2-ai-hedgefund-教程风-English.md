## Quick Deployment Tutorial

### Environment Setup

```bash
# Clone project
git clone https://github.com/virattt/ai-hedge-fund.git

# Install dependencies
cd ai-hedge-fund
poetry install

# Configure API
cp .env.example .env
# Add your OpenAI API Key
```

### Run Demo

```bash
poetry run python -m app
```
