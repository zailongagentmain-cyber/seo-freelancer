## YouTube SEO优化

### 1. YouTube关键词研究

```
目标关键词:
- 高流量商业关键词
- "如何做"和教程查询
- 产品评论搜索
- 问题解决查询
```

使用的工具:
- YouTube自动完成
- TubeBuddy, VidIQ
- Google关键词规划师
- 竞品分析

### 2. 标题优化

最佳实践:
- 将目标关键词放在开头
- 标题保持在60个字符以内
- 使用强力词汇: "Complete," "Ultimate," "Guide"
- 添加年份以显示时效性: "2026"

示例:
```
✅ "Complete YouTube SEO Guide 2026 - Rank #1"
❌ "My YouTube Video About Marketing"
```

### 3. 描述写作

你的描述应该:
- 前150个词最重要
- 包含主要和次要关键词
- 为长视频添加时间戳
- 添加资源链接

模板:
```
[钩子 - 1-2句话]
在本视频中，你将学习[好处]。

[时间戳]
0:00 简介
0:30 关键词研究
2:15 标题优化
...

[要点]
- 要点1
- 要点2
- 要点3

[行动号召]
订阅更多SEO技巧!

[链接]
- 博客: example.com
- 工具: example.com/tool
```

### 4. 标签策略

使用混合:
- 主要关键词标签
- 次要关键词标签
- 广泛类别标签
- 竞品频道名称
- 热门相关标签

### 5. 缩略图优化

缩略图决定点击率:
- 使用高对比度颜色
- 添加大而可读的文字
- 相关时添加人脸
- 保持一致的品牌风格
- 测试不同设计

### 6. 视频Schema标记

为你的页面添加VideoObject schema:

```json
{
  "@context": "https://schema.org",
  "@type": "VideoObject",
  "name": "视频标题",
  "description": "视频描述",
  "thumbnailUrl": "https://example.com/thumb.jpg",
  "uploadDate": "2026-03-14",
  "duration": "PT10M30S",
  "embedUrl": "https://www.youtube.com/embed/VIDEO_ID"
}
```

## TikTok SEO优化

### 1. 理解TikTok搜索

TikTok的搜索算法与Google不同:
- 更重视时效性
- 参与度信号至关重要
- 通过话题标签发现内容
- "For You Page" vs. 搜索意图

### 2. TikTok关键词策略

研究关键词:
- 使用TikTok的搜索自动完成
- 检查热门声音和话题标签
- 分析你领域中的热门内容
- 专注于对话式、自然语言

### 3. 话题标签策略

最佳实践:
- 混合广泛和细分话题标签
- 每个视频最多3-5个话题标签
- 包含相关热门话题标签
- 创建品牌话题标签

示例:
```
#seo #seotips #digitalmarketing #marketingstrategy #2026
```

### 4. 视频优化

- 在前1-3秒内吸引观众
- 为关键点添加文字叠加
- 添加无障碍字幕
- 利用热门声音
- 以明确的CTA结束

### 5. TikTok SEO vs. YouTube SEO

| 因素 | YouTube | TikTok |
|--------|---------|--------|
| 视频长度 | 10-20分钟最佳 | 15-60秒最佳 |
| 关键词 | 在标题、描述中 | 在 caption、话题标签中 |
| 时效性 | 不太重要 | 非常重要 |
| 参与度 | 订阅者重要 | 总参与度重要 |
| 算法 | 观看时间 | 观看时间 + 分享 |

## 视频内容策略

### 1. 内容再利用

将一个视频转化为多个内容:
- 长YouTube视频 → 短TikTok片段
- 教程视频 → 博客文章 + 视频嵌入
- 产品演示 → 对比视频
- 直播 → 高光集锦

### 2. 视频+文章矩阵

创建互补内容:
- YouTube视频 + 博客详细文章
- 短TikTok + 更长的Instagram Reel
- 演示视频 + FAQ文档

### 3. 衡量成功

跟踪这些指标:

**YouTube:**
- 观看时间和观众留存率
- 点击率(CTR)
- 订阅者增长
- 搜索展示

**TikTok:**
- 观看时间和观看时长
- 参与率(点赞/评论/分享)
- 个人资料访问
- 话题标签表现

## 常见视频SEO错误

1. **忽略视频文件**: 尽可能直接上传
2. **音频质量差**: 投资好的麦克风
3. **没有字幕**: 添加字幕以提高可访问性和SEO
4. **发布不一致**: 保持定期发布计划
5. **忽视移动端**: 优化移动优先观看
6. **没有CTA**: 始终包含行动号召
